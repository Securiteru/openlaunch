# Security policy

## What this repo must never contain

- Credentials, API keys, session cookies, or tokens — for any platform
- Private product data (unreleased details, real maker contact info you
  haven't agreed to publish)
- Real user data collected during submissions

Product briefs under `products/` are public by default in this repo. Keep
real launch work in a private fork and PR back only playbook improvements —
see `products/README.md`.

## Reporting

Open a private report via GitHub Security Advisories, or open an issue
without including the sensitive material itself.
